# ESP32S3 and INMP441 Microphone and MAX98357A Digital Amplifier Connections

- **ESP32S3 GPIO4** → **INMP441 WS**
- **ESP32S3 GPIO5** → **INMP441 SCK**
- **ESP32S3 GPIO6** → **INMP441 SD**
- **ESP32S3 GPIO7** → **MAX98357A DIN**
- **ESP32S3 GPIO15** → **MAX98357A BCLK**
- **ESP32S3 GPIO16** → **MAX98357A LRC**
